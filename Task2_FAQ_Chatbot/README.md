# FAQ Chatbot 🤖

## CodeAlpha AI Internship – Task 2

This project is an FAQ Chatbot developed as part of the CodeAlpha AI Internship Task 2.

The chatbot allows users to ask questions and provides the most relevant answer from a predefined FAQ dataset using NLP-based text processing and similarity matching.

## 🚀 Features

- Simple and user-friendly chatbot interface
- Contains multiple FAQ questions and answers
- NLP-based text processing
- TF-IDF based similarity matching
- Cosine similarity for finding relevant FAQs
- Displays the best matching answer
- Easy to use and understand

## 🧠 Technologies Used

- HTML
- CSS
- JavaScript
- NLP / Text Processing
- TF-IDF
- Cosine Similarity

## ⚙️ How It Works

1. The user enters a question in the chatbot.
2. The question is processed using text preprocessing techniques.
3. TF-IDF is used to represent the text.
4. Cosine similarity compares the user's question with the stored FAQ questions.
5. The chatbot identifies the most relevant FAQ.
6. The corresponding answer is displayed to the user.
